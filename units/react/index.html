React

React is a small idea — the interface is a function of state — surrounded by a large amount of accumulated machinery for making that idea fast. This unit teaches the idea first, then each piece of machinery as an answer to a problem you have already felt. Twenty-four chapters, each one a page you can read end to end.

·How to use this unit

React is easy to use badly for a long time before anything visibly breaks. This unit is aimed at the point where it starts to.

Every chapter is one HTML page in this folder. Nothing loads from a server and nothing loads from a parent directory. The demos run real code — several of them implement the thing being described, so when a chapter says a parent re-render cascades, or that a stale closure captures an old value, there is a control on the page that lets you cause it and watch the count move.

This unit assumes you can write JavaScript. If this, closures, the event loop or module semantics are shaky, read Part 4 of the Front-end Developer unit first — React amplifies gaps in the language rather than hiding them. That unit's Chapter 18 also explains what React is doing relative to Vue, Svelte and Solid, which is useful context this unit does not repeat.

New to React

Straight through. Parts 1 and 2 are the whole mental model and everything later is a consequence of them; the temptation to skip to data fetching is the main way people end up confused six months in.

A note on versions and on churn

This unit is written against modern React: function components, hooks, concurrent rendering, and the server-component model. Class components appear only where you will meet them in existing code — error boundaries, and legacy files. Where a chapter names a library it is because a vague chapter would be useless, but each is introduced as the answer to a specific problem, so the reasoning survives the library being replaced. React's own API has been unusually stable for a decade; the ecosystem around it has not.

Self-contained by design

Everything this unit needs lives in this folder: index.html, chNN.html and assets/. Copy the folder to a USB stick, a phone, a plane — it still works. The only outbound link is the one back to the catalogue in the breadcrumb, and it is optional.

How a chapter is built

Intuition first, then the precise rule, then code you can run, then a demo wired to the real behaviour. Comparison tables where a decision has to be made, and self-check questions at the end that hide their answers until you ask.
