JavaScript

Twenty chapters on the language itself — not a tour of frameworks, but how JavaScript actually works. Values and coercion, scope and hoisting, closures, this and the prototype chain that classes sit on, the built-in collections, iterators and generators, then the event loop and promises, modules, the DOM, memory and tooling. Interactive demos throughout, because the event loop and the prototype chain are easier to watch than to describe.

20 chapters9 partsAssumes: you can write a loopTargets: modern browsers and current Node.js

Every chapter is one page in this folder. Pages link to each other but depend on nothing outside it, so you can copy the folder anywhere and open any page offline.

If JavaScript is your first language

Read chapters 1 to 6 in order and type every example. Values and coercion in chapter 2 repay slow reading more than anything else here.

  1. Chapters 1 – 6, with the browser console open
  2. Chapters 7 – 9 — objects
  3. Build something small
  4. Chapters 14 – 15 when the basics feel automatic

If you code in another language

The syntax will take an afternoon. What will bite you is coercion, this, prototypes and the event loop.

  1. Chapters 2 and 4 — coercion and equality
  2. Chapter 3 — hoisting and the temporal dead zone
  3. Chapters 7 – 8 — this and prototypes
  4. Chapter 14 — the event loop

If you write JavaScript daily already

Skip to the parts most people never formalise: the iteration protocols, the scheduling model, and what the engine does with memory.

  1. Chapter 13 — iterators and generators
  2. Chapters 14 – 15 — the event loop and promises
  3. Chapter 16 — modules
  4. Chapter 18 before optimising anything

How a chapter is built

Mechanism, not recipes

Why the language behaves as it does, so you can predict its behaviour in cases nobody wrote a tutorial for.

Runnable examples

Every code block is real JavaScript you can paste into the browser console or Node.js, with the output shown as a comment.

The traps, named

Loose-equality coercion, closures over a var loop counter, the temporal dead zone, unhandled promise rejections — each with the mechanism that causes it.

Self-checks

Questions with hidden answers at the end of each chapter. Attempt before revealing.
