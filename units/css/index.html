CSS

Twenty-four chapters on how CSS actually decides what you see — not a catalogue of properties. The cascade and specificity, the box model and normal flow, margin collapse, containing blocks and stacking contexts, then flexbox, grid and intrinsic sizing, responsive queries, typography and colour, motion, custom properties and the maths functions, and finally the craft: accessibility, rendering performance, design tokens and architecture. Every chapter has interactive demos, because most CSS surprises are rules you can watch being applied.

24 chapters8 partsAssumes: you have written some HTML and CSSTargets: current evergreen browsers

Every chapter is one page in this folder. Pages link to each other but depend on nothing outside it, so you can copy the folder anywhere and open any page offline.

If CSS mostly feels like trial and error

Read the first two parts in order with developer tools open. Nearly every "why is this not applying" moment is the cascade, the box model or a containing block.

  1. Chapters 1 – 2 — how a declaration wins
  2. Chapters 3 – 5 — boxes, flow and margin collapse
  3. Chapters 6 – 7 — position and stacking contexts
  4. Then chapters 8 – 10

If you need layouts to behave

The layout systems and the sizing rules underneath them, then the queries that adapt a layout to its space.

  1. Chapter 4 — normal flow first
  2. Chapters 8 – 9 — flexbox and grid
  3. Chapter 10 — intrinsic sizing
  4. Chapters 11 and 19 — queries and clamp()

If you write CSS daily already

Skip to the parts most people never formalise: modern colour, motion, the newer language features, and keeping a large stylesheet maintainable.

  1. Chapter 13 — colour spaces
  2. Chapters 18 – 20 — custom properties, maths, layers
  3. Chapters 21 – 22 — accessibility and performance
  4. Chapters 23 – 24 — tokens and architecture

How a chapter is built

Mechanism, not recipes

Why the browser resolves a style the way it does, so you can predict the result in cases nobody wrote a tutorial for.

Measured, not asserted

Demos apply the real rules to real elements in the page, so the numbers you see are what your browser computed.

The traps, named

Margin collapse, a z-index that never wins, flex: 1 versus flex: auto, transitions that do nothing — each with the rule that causes it.

Self-checks

Questions with hidden answers at the end of each chapter. Attempt before revealing.
