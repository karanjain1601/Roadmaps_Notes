Backend Developer

Twenty-two chapters on what happens after the request leaves the browser. The protocol, the server, the database and what it costs, the caches, the security you cannot skip, and the architecture and operations that decide whether any of it survives contact with real traffic. The moving parts run live in the page — trace a request hop by hop, watch an index turn a scan into a seek, break a transaction with a phantom read. The unit is complete: all twenty-two chapters, 44 interactive demos, and a closing reference with a searchable glossary and a 61-question self-quiz.

What this unit assumes and what it does not

It assumes you can write code in some language and have used a database at least once. It does not assume any particular stack — examples are Python and SQL because they read clearly, but almost nothing here is language-specific. Where a choice is genuinely contested, both sides get made rather than one being asserted.
