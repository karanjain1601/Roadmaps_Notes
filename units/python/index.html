Python

Twenty chapters on the language itself — not a tour of libraries, but how Python actually works. The object model that explains half of all beginner confusion, the data structures and their costs, functions and closures, classes and the protocols behind them, generators, decorators, typing, concurrency and the GIL, then the craft: testing, profiling, packaging and tooling. Interactive demos throughout, because a reference graph is easier to see than to describe.

20 chapters5 partsAssumes: you can write a loopTargets: Python 3.11+

Every chapter is one page in this folder. Pages link to each other but depend on nothing outside it, so you can copy the folder anywhere and open any page offline.

If Python is your first language

Read chapters 1 to 8 in order and type every example. The object model in chapter 2 repays slow reading more than anything else here.

  1. Chapters 1 – 5, with the REPL open
  2. Chapters 6 – 8
  3. Build something small
  4. Chapters 9 – 11 when the basics feel automatic

If you code in another language

The syntax will take an afternoon. What will bite you is the object model, mutability and the import system.

  1. Chapter 2 — names are not variables
  2. Chapter 4 — costs and choices
  3. Chapters 6 – 8 — imports, classes, exceptions
  4. Chapters 9 – 11 — what idiomatic looks like

If you write Python daily already

Skip to the parts most people never formalise: the protocol layer, the type system, and everything about shipping.

  1. Chapters 9 – 11
  2. Chapter 14 — concurrency and the GIL
  3. Chapters 15 – 19 — the craft half
  4. Chapter 17 before optimising anything

How a chapter is built

Mechanism, not recipes

Why the language behaves as it does, so you can predict its behaviour in cases nobody wrote a tutorial for.

Runnable examples

Every code block is real Python you can paste into a REPL, with the output shown as a comment.

The traps, named

Mutable defaults, late binding, shallow copies, circular imports — each with the mechanism that causes it.

Self-checks

Questions with hidden answers at the end of each chapter. Attempt before revealing.
