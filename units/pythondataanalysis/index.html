Python for Data Analysis

Getting an answer out of a dataset is the easy part. Getting an answer you would defend in a meeting requires knowing which of your choices changed it — and cleaning decisions, bin widths, imputation strategies and grouping levels all change it, usually silently. This unit is about the analysis you can stand behind, with the effect of each decision measured rather than described.

WHAT THIS ASSUMES

No Python. Some comfort with data in any form — a spreadsheet, a SQL query, a report — is enough. Where a chapter leans on a neighbouring unit it says so and links across.

WHAT IT DELIBERATELY OMITS

Machine learning modelling, which has its own unit, and library API tours that go stale. The aim is that you can read the documentation quickly rather than memorise a method list.

HOW THE DEMOS WORK

Each one generates a dataset and computes the real statistic in the page — an actual correlation, an actual imputation, an actual histogram. They are built so you can change a decision and watch the answer move.
