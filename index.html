How a unit works

Each roadmap is a folder at units/<name>/ holding a contents page, one page per chapter, and its own assets/. Copy the folder anywhere and it still works — no server, no index, no siblings.

What's inside one

Every topic gets a full chapter: intuition first, then the mechanism, then runnable code. Diagrams for structure, comparison tables for decisions, and an interactive demo wired to the real logic so you can break it on purpose.

Keeping this page current

Two lists near the top of the source drive everything. A unit's name sits in IN_PROGRESS while it is being written and moves to WRITTEN when the last chapter lands.
